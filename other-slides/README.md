# Additional slides

Presentations outside the module program: breakdowns of individual topics that are not tied to the homework
of a specific module.

## What is here

- **[`m1-agents-prompting.html`](m1-agents-prompting.html)** — "Prompting best practices":
  why a coding agent has a different cost of error than a chatbot; five elements of a prompt; five
  ways to give context; constraints and verification; dosing the task; eight anti-patterns
  with a breakdown of each; a demo and two exercises.

## How to open

Download the file and open it with a double click in a browser. No server needed, no internet needed: fonts,
styles and all illustrations are embedded inside, zero external requests. Hence the file size.

## How to read

Arrow keys flip through the screens. The top bar shows the sections and jumps to the one you click.

On list screens **clicking any item opens a window with the breakdown**: the slide itself holds
the thesis, and behind the click is the full text, code and caveats for it. The window is closed with `Esc`, the cross or a click
on the dimmed backdrop.

**Pictures are clickable too** and expand to full screen. They close the same way.
