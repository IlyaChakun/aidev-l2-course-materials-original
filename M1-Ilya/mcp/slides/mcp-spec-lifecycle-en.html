The ecosystem is catching up

An independent census (RoninForge state-of-mcp) probes every server in the official MCP Registry it can reach and checks four things the new revision requires: server/discover, calls without the handshake, no dependence on sessions, and the new routing headers.

4,937
servers reachable on 22 Jul 2026, out of 18,032 in the registry
0
passed all four checks that day, a week before the release
81%
already handled calls without the handshake, the biggest single change
31
passed all four by 13 Sep 2026

The takeaway: most servers, and most tutorials online, still describe the old protocol.
