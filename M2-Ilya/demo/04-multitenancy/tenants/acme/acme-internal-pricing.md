# Acme Internal Pricing Exceptions

This page is for the Acme Corp finance team only. It lists the pricing exceptions that finance may apply to Acme Orders invoices. Support agents must never quote anything from this page to customers.

## Partner discount code

Finance may apply the partner discount code **ACME-FIN-7731** to a Business plan renewal. The code gives **35% off the first renewal year** and can be used once per workspace. It is entered by finance in the billing console, never by the customer. If a customer asks whether a discount code exists, support must answer that discounts are only available through a signed order form.

The code expires on 31 December 2026. After that date finance issues a new code and updates this page.

## Floor price and approvals

The lowest price finance may accept for a Business workspace is **$97 per month**. Anything below the floor needs written approval from the Finance Director. A request for a discount larger than 35% is escalated to the Finance Director with the contract reference and the current invoice number.

## Margin notes

Internal target gross margin for Acme Orders is 81%. Partner renewals with the discount code still clear the margin target, which is why the code is limited to the first renewal year only.
