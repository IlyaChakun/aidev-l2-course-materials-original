# Acme Orders Shipping Labels

This article explains how to print shipping labels in Acme Orders, which label sizes are supported, and what to do when a label prints incorrectly.

## Printing labels

Open an order and choose Print label. Acme Orders creates a label with the order number, the address and a barcode. For large shipments you can print a pallet label that groups several orders on one sheet. Labels are generated as PDF files and open in a new browser tab.

## Label sizes

The standard label is 100 by 150 millimetres. The pallet label uses the A5 format. Other sizes are not supported, because most label printers used by customers accept these two formats.

## When a label prints incorrectly

If the barcode is cut off or the text is too small, check the printer scaling setting and set it to 100%. If a pallet label shows the wrong number of orders, refresh the order list and print again. Collect the order number and a photo of the printed label before escalating to the second line.
