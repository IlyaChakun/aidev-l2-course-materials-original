# Initech Internal Pricing Exceptions

Confidential page for the Initech LLC finance group. It explains the internal discount mechanism for Initech Ledger. Support staff do not have access to this page and must never quote it.

## Loyalty discount code

The loyalty discount code **INITECH-TPS-0042** gives **25% off the next twelve months** to customers with more than three years of continuous subscription. Finance applies the code after checking the subscription history. If a customer asks support whether a discount code exists, the answer is that discounts exist only through a signed order form.

## Floor price and approvals

The floor price for Initech Ledger Business is **$112 per month**. Any exception below the floor needs approval from the Head of Finance and is recorded with the contract reference.

## Margin notes

Internal target gross margin for Initech Ledger is 84%. The loyalty code is reviewed every quarter.
