# Module 1 slides

`m1-slides.html` is the presentation for the "Advanced MCP" module.

## How to open

Download the file and open it with a double click in a browser. No server and no internet needed: fonts,
styles, images and the full texts of the seven guides are embedded inside, with zero external requests.

## How to read

Arrow keys move between screens. On list screens, **clicking any item opens a window with a walkthrough**:
the slide itself holds the thesis, and behind the click are the full text, code and quotes from primary sources. Close
the window with `Esc`, the close button or a click on the dimmed backdrop.

On the "Program" screen the rows are clickable: a click on a block jumps to its first slide.

At the end of each block there is a guide screen. Its button opens the whole guide for the block's topic
right inside the presentation, and the last item holds all the links that were mentioned in the block.
The same guides as text are in the folder [`../guides/`](../guides/).
