The player reads runs/log/index.json and the logs runs/log/<run_id>.json of schema langgraph-runlog/1. The log is written by runlog.RunRecorder — a regular LangChain callback handler that can be passed in config["callbacks"] of any LangGraph graph. It recognizes nodes from the langgraph_node/langgraph_step metadata, LLM calls — from chat model events, tools — from tool events, checkpoints — from graph.get_state_history(). Details and how to adapt it to your own graph — README.md.
