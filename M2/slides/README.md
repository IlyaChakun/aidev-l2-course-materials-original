# Module 2 slides

`m2-slides.html` — the presentation for the module "Context management: RAG and CAG".

## How to open

Download the file and open it with a double click in a browser. No server is needed, no internet is
needed: the fonts, styles and all the illustrations are embedded inside, with zero external
requests. Hence the file size: the pictures are inside the HTML itself.

## How to read

The arrows page through the screens. The top ribbon shows the session's sections and takes you to
the one you need on click.

On the list screens **a click on any item opens a window with the breakdown**: the slide itself
holds the thesis, and under the click are the full text, code, numbers and caveats to them. The
window is closed with `Esc`, the close button or a click on the dimmed backdrop.

**The pictures are clickable too** and expand to full screen: where a diagram has small details,
this is the only way to make them out. They are closed the same way.

The links to the helper documents lead to the [`../artifacts/`](../artifacts/) folder of this
repository. The same material lies there as text, and it is easier to read it there than from a
slide.
